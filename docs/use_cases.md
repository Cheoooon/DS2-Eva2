# Use Cases

## Roles & Auth
- Admin: Create/Assign staff roles.
- Staff: Manage tables, reservations, internal chat.
- Client: Auth required for effective reservation.

## Reservations
- Real-time availability check.
- Book, cancel (if >1 day), modify reservation.
- Trazability: Status changes instead of deletion.

## Admin/Staff
- Table configuration (recurring, exclusions).
- Real-time sync.
- Chat with client.
