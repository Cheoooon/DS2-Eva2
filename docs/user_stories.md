# Casos de Uso (User Stories)

## Gestión de Reservas
1. **Crear Reserva**: Como STAFF, necesito crear una reserva indicando mesa, horario y cliente, para asegurar la disponibilidad.
2. **Editar Reserva**: Como STAFF, necesito modificar una reserva existente (cambio de mesa o horario) ante un imprevisto.
3. **Cancelar Reserva**: Como STAFF/ADMIN, necesito cancelar una reserva siguiendo la política de cancelación.

## Gestión de Mesas
1. **Configurar Capacidad**: Como ADMIN, necesito configurar las mesas del restaurante para reflejar la distribución real.

## Autenticación
1. **Acceso Diferenciado**: Como ADMIN, debo acceder a la configuración global. Como STAFF, solo debo acceder a la operativa de reservas.
